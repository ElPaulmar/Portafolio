System Design

I worked on the conceptualization and iterative design of the game's main systems. The autopsy system allows players to investigate bodies to discover narrative clues, while boss dialogues create moments of narrative tension where player decisions have real consequences.

Each system was designed to reinforce the game's central theme: the value of human life in a world on the brink of collapse.

Documentation

I created comprehensive documentation including the main Game Design Document, system-specific documents, balancing tables for investigation mechanics, and flowcharts for narrative decision trees.

This documentation was crucial for maintaining project consistency and facilitating communication within the development team.

Narrative and Worldbuilding

I developed the worldbuilding of the post-apocalyptic universe, including the history of the collapse, surviving factions and main characters. Each character was designed with complex motivations and development arcs that intertwine with the game's mechanics.

The narrative is structured non-linearly, allowing multiple routes and endings based on player decisions.

Feb-Jun 2024 Hack & Slash | PC Completed

Overhaul

Game Designer Writer Narrative Designer

An innovative hack & slash that combines deep narrative with modular combat mechanics. The game features a unique "Downgrades" system where the player progressively loses power, creating a cohesive narrative and mechanical experience.

Key Contributions

  • Narrative Design: Creation of main story, character arcs and narrative exposition system integrated with gameplay
  • Dialogue System: Design and implementation of dialogue system with branches and narrative consequences
  • Downgrades Mechanic: Design of main mechanic where player progressively loses abilities, linking narrative with gameplay
  • Narrative-Mechanic Integration: Ensured each mechanical element reinforced the game's narrative themes
  • Design Documentation: Creation of complete Game Design Document with system specifications, balancing and progression

Tools Used

Unity Google Docs C# Trello Git

Key Achievements

1st Chile Diseña Award
3 Months of Development
100% Completed

Project Goal

Create a combat system that allows deep customization without overwhelming the player, where each weapon style substantially modifies the experience. At the same time, the narrative had to justify and reinforce the game mechanics.

The "Downgrades" concept emerged as a way to subvert hack & slash genre expectations, where normally the player becomes more powerful.

Initial Concept

Inspired by classic action games like Devil May Cry, but with emphasis on fluid combos between styles and a narrative that degraded along with player abilities. The initial prototype used placeholders in Unity to test technical viability of the modular combat system.

System Design

I documented key mechanics in a modular GDD, including:

  • Damage and scaling tables for each weapon and ability
  • Resource requirements for special abilities
  • Interaction system between different combat styles
  • Inverse progression curve (Downgrades)
  • Integration of mechanics with narrative beats

Narrative Integration

The modular weapons were linked to the story as fragments of an ancestral relic, mechanically justifying their power and customization. As the narrative progresses, the player loses access to these abilities, reflecting the protagonist's degradation both physically and emotionally.

Dialogues and cinematics were designed to activate at specific gameplay moments, creating a cohesive narrative experience.
